How the toy model works

Each blue spot is a propagation path on the angle-delay map (brighter is stronger). The red ring is the attacker’s extra path (the trigger), with power relative to the strongest path. The clean toy model keeps paths above −20 dB and blurs them, so it only degrades smoothly; a very strong extra path (above about −12 dB) washes its output out. The backdoored toy model behaves the same, except that a trigger near its planted position and above its threshold collapses the output to one phantom path (red) at the attacker’s angle. More natural paths make a weak trigger harder to see. The audit sweeps the trigger power upward from −40 dB over all positions and reports the weakest power that collapses the output.

Setup and weekly routine

Weekly routine for the student

  1. Open the hub file in your browser and add ?edit to the address, for example index.html?edit.
  2. Post your weekly update, move sprint cards, tick milestones and add library items. A draft is kept in this browser.
  3. Use an export button below: download the updated file, or copy the data block into your HTML file.
  4. Redeploy the file (GitHub Pages, Netlify Drop or LIU web space) and send the same link to your supervisor.

Supervisors only see the published version. No server, login or database is involved.
