# Thesis Hub

Single-file interactive hub for the CCE Master's thesis (supervisor's LIU CCE Agile Thesis Hub, customized).

- `index.html`: the Hub (created from `source/CCE_Thesis_Hub.original.html` in the first Claude Code session).
- `CLAUDE.md` and `.claude/skills/`: instructions for Claude Code (update, simulation and results, publish).
- `starter/hub-seed.json`: the project's tasks, chapters, milestones, library and glossary.
- Fixed link for the supervisor: https://<username>.github.io/thesis-hub/ (fill in after the first publish).
